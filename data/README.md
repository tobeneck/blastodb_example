# BlastoDB example data

This directory contains **example downloadable data** used by the GitHub Pages demo site.

## FASTA files

Location: `data/fasta/`

Files:
- `Blastocystis_ST1.fasta`
- `Blastocystis_ST2.fasta`
- `Blastocystis_ST3.fasta`
- `Blastocystis_ST4.fasta`
- `Blastocystis_ST5.fasta`
- `Blastocystis_ST6.fasta`
- `Blastocystis_ST7.fasta`
- `Blastocystis_ST1-7.fasta` (combined)

### Provenance

These FASTA files were downloaded from the links present on:
- https://www.blastodb.com/subtypes

They include sequences labeled with accession-like identifiers in the FASTA headers.

### Citation

If you use these sequences in analysis, please cite the primary sources for the sequences (e.g., GenBank accessions) and any relevant BlastoDB publication / website reference.

## Notes

- Culture microbiome/metabolome downloads are not included in this example because the corresponding links on the source page are currently empty.
